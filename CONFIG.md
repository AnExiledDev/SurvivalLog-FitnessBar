# Fitness Bar settings

Settings live in `BepInEx\config\com.dev.survivallog.fitnessbar.cfg`, created the first time the game starts with the mod. Change them in game on the Mod Manager's Mods screen, or edit the file while the game is closed. Changes on the Mods screen take effect at once. Delete the file to get the defaults back.

## FitnessBar

| Setting | Default | What it does |
| --- | --- | --- |
| `Enabled` | `true` | Shows the Fitness bar under the Life bar. `false` turns the mod off and leaves the HUD unchanged. While Vital Signs shows its Fitness bar, the mod stays off either way, so only one bar shows. |
