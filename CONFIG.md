# Fitness Bar settings

Settings live in `BepInEx\config\com.dev.survivallog.fitnessbar.cfg`, created the first time the game starts with the mod. Change them in game on the Mod Manager's Mods screen, or edit the file while the game is closed. Changes take effect at the next game start. Delete the file to get the defaults back.

## FitnessBar

| Setting | Default | What it does |
| --- | --- | --- |
| `Enabled` | `true` | Shows the Fitness bar under the Life bar. `false` turns the mod off and the HUD stays as the game draws it. Takes effect at the next game start. |
